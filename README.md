# Locale test card

ATLAS exported Card verification fixture, version 0.1.1. This separate repository
tests real GitHub/HACS registration and delivery in isolated Home Assistant.
It is not the ATLAS Runtime integration and does not change existing projects.
The included demo entities must be replaced before use. Release 0.1.0 contains
marked English fallbacks; 0.1.1 adds manually authored EN/DE/FR verification
titles and DE/FR messages to make an update/restore cycle visibly testable.
Existing field names, entities, project structure and runtime behavior are retained.

Generated by ATLAS Home Assistant Card Editor.

## HACS repository installation

Extract the complete bundle at the root of a dedicated GitHub repository named atlas-hacs-delivery-card. Add that repository to HACS as a Dashboard repository.
Keep the script and locales under dist/. HACS installs them together into www/community/<repository>/ and registers the script as a module. Do not copy the script to the repository root or attach a standalone JavaScript release asset, which HACS may select instead of dist/.
Branch/tag installs use this layout; the ZIP is an export container, not a zip_release asset. Existing root-layout ATLAS bundles remain importable. HACS 2.0.5 filenames beginning with dist are blocked at export because that version can omit nested language files.

## Lovelace resource

Replace the demo entities with your own Home Assistant entities before using this card in production.

## Languages

Included language files: en, de, fr.
Keep the script and its sibling `locales/` directory together on the same Home Assistant origin; register the script as a JavaScript module.
The script uses the Home Assistant language, or an explicit card `language` such as `de` or `fr`. Regional variants use their base language.
Missing, invalid or incomplete translations fall back to `locales/en.json`, then embedded English defaults. Locale requests send no credentials.
The localized project title, missing-entity hint and runtime failure text are applied without changing authored child-card names or entity IDs. A distinct explicit `title` or `replacement_hint` takes priority.
A script-only installation works with embedded English defaults. This repository bundle places the script and locales in dist/ so HACS installs them together. Keep dist/ intact; do not copy the script to the repository root or attach a standalone JavaScript release asset, which HACS can prefer over dist/.

Release 0.1.1 includes manually authored verification texts in EN/DE/FR.
Release 0.1.0 retains the original English fallback files. These examples are
not a claim of complete ATLAS product translation.
